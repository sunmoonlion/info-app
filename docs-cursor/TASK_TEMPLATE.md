# 任务卡模板（TASK TEMPLATE）

文件命名：`docs-cursor/tasks/TASK-XXXX-<slug>.md`

---

```markdown
# TASK-XXXX：<名称>

- 状态：待开始 / 进行中 / 完成 / 阻塞
- 日期：YYYY-MM-DD

## 目标

一句话说清楚要做什么。

## In Scope（做）

- {{具体事项}}

## Out of Scope（不做）

- {{明确排除，防止范围蔓延}}

## 前置依赖

- 接口已确认（见 API_CONTRACT.md {{章节}}）
- {{其他前置条件}}

## 风险点

- {{可能遇到的问题}}

## 验收标准

执行以下步骤后，应该看到什么：
1. {{步骤 1}} → {{期望结果}}
2. {{步骤 2}} → {{期望结果}}

## 结果记录

### 改动文件

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `path/to/file` | 新建 / 修改 | {{一句话说明}} |

### 验证结果

{{通过 / 部分通过 / 失败，附说明}}

### 已知问题

{{遗留问题，附 ISSUE_LOG 编号}}

### 下一步

{{下一个最小任务建议}}
```

---

## 示例

```markdown
# TASK-0001：登录页面

- 状态：完成
- 日期：YYYY-MM-DD

## 目标

实现登录页，对接 Casdoor OIDC 流程，登录成功后跳转首页。

## In Scope

- 登录页 UI
- 点击登录跳转 Casdoor
- 回调页面处理

## Out of Scope

- 第三方登录
- 记住密码

## 前置依赖

- 接口已确认（见 API_CONTRACT.md 认证模块）

## 风险点

- Casdoor redirect URI 配置可能不匹配

## 验收标准

1. 访问 /login → 页面正常渲染
2. 点击登录 → 跳转 Casdoor 授权页
3. 授权后 → 跳回应用，已登录状态

## 结果记录

### 改动文件

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `src/pages/login.vue` | 新建 | 登录页 |

### 验证结果

全部通过。

### 已知问题

无。

### 下一步

TASK-0002：首页文章列表
```
