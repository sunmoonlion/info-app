# 术语表（GLOSSARY）

> 统一项目内使用的关键词，避免沟通歧义。
> 新增术语时在此追加。

---

## 项目与流程术语

- **样板项目**：用于沉淀可复用开发流程、规则、文档模板的示范项目。
- **主链路**：项目最核心的业务闭环（如登录 → 核心功能 → 数据展示）。
- **基线（Baseline）**：当前被确认"可运行、可验证"的版本与环境状态。
- **门禁（Gate）**：任务进入下一阶段前必须满足的检查条件。
- **DoD（Definition of Done）**：任务"完成"所需满足的统一标准。
- **MVP**：最小可用产品/能力，强调先可用再完善。

## 架构与技术术语

- **BFF（Backend for Frontend）**：专为特定前端提供的后端层，负责处理 OIDC 回调、聚合接口等。
- **OIDC**：OpenID Connect，基于 OAuth2 的身份认证协议。
- **Session**：服务端存储的会话，客户端通过 `session_id`（HTTP-only Cookie）引用。
- **HTTP-only Cookie**：浏览器无法通过 JS 访问的 Cookie，防止 XSS 窃取 token。
- **Redis**：用于存储 Session / 缓存的内存数据库。
- **Casdoor**：统一认证中心，提供 OIDC/OAuth2 服务。

## 接口术语

- **接口契约**：接口路径、方法、参数、响应结构、错误码等约定集合。
- **冒烟测试**：验证系统主功能是否基本可用的最小测试集合。
- **适配层**：前端统一封装请求、错误处理、字段兼容的中间层。

## 协作术语

- **任务卡**：单个任务的标准记录载体（目标 / 范围 / 验收 / 验证 / 结果）。
- **决策日志**：对关键架构与流程决策的背景、方案、影响记录（见 `DECISION_LOG.md`）。
- **风险登记**：对项目已识别风险的持续跟踪（见 `RISK_REGISTER.md`）。
