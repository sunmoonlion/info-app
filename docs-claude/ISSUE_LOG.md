# 问题日志（ISSUE LOG）

> 记录开发过程中发现的问题，无论是否在当前范围内。
> 发现即记录，不拖着；处置后更新状态。

---

## 格式

```
## ISSUE-XXXX：<标题>

- 发现日期：YYYY-MM-DD
- 状态：Open / In Progress / Closed
- 发现于：<任务卡编号 or 模块名>

**现象**：
<描述看到了什么>

**影响**：
<影响范围，是否阻断主链路>

**处置**：
<已做了什么 / 计划怎么做 / 为什么暂时搁置>
```
